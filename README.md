
# Лабораторна робота №2

**Дисципліна:** Технології розробки на платформі Java

**Тема:** Збірка проєкту за допомогою Gradle та робота з Java Collections Framework

## Мета роботи

Навчитися налаштовувати Java-проєкт за допомогою Gradle, використовувати Version Catalog для керування залежностями, працювати зі стандартними колекціями Java та обробляти граничні випадки.

## Варіант завдання

Номер залікової книжки: 20.

Варіант визначається за формулою:

V = N mod 3 = 20 mod 3 = 2

**Варіант 2 — Частотний аналізатор тексту.**

Необхідно реалізувати клас `WordCounter`, який виконує підрахунок частоти слів у тексті та формує множину унікальних слів.

## Опис реалізації

Проєкт містить клас `WordCounter`, розташований у пакеті `ua.kpi.comsys.collections`.

У класі реалізовано два основні методи:

- `countWords(List<String> textLines)` — підраховує кількість входжень кожного слова та повертає `Map<String, Integer>`.
- `getUniqueWords(List<String> textLines)` — знаходить усі унікальні слова та повертає `Set<String>`.

Для обробки тексту використовується допоміжний метод `extractWords()`, який розділяє рядки на окремі слова.

Під час обробки тексту:
- усі слова переводяться в нижній регістр;
- словом вважається послідовність латинських букв і цифр;
- розділові знаки використовуються як роздільники;
- порожні слова ігноруються;
- при передачі `null` замість списку викидається `IllegalArgumentException`.

## Використані колекції

У програмі використано стандартні колекції Java:

- `List` — для зберігання вхідних рядків тексту;
- `ArrayList` — для зберігання слів після розбиття рядка;
- `HashMap` — для підрахунку кількості входжень слів;
- `HashSet` — для зберігання унікальних слів.

Сторонні бібліотеки для роботи з колекціями не використовувалися.

## Тестування

Для перевірки роботи програми створено клас `WordCounterTest`, у якому реалізовано 16 автоматичних тестів із використанням JUnit 5.

Тести перевіряють:
- правильність підрахунку частоти слів;
- отримання унікальних слів;
- обробку великих і малих літер;
- роботу з цифрами та спеціальними символами;
- обробку порожніх списків і рядків;
- обробку `null` як вхідного аргументу;
- обробку `null` серед елементів списку.

Усі 16 тестів успішно пройдено.

## Запуск проєкту

Для роботи з проєктом необхідно мати встановлену JDK 27.

Збірка проєкту:

    ./gradlew build

Запуск автоматичних тестів:

    ./gradlew test

Очищення та повторна збірка:

    ./gradlew clean build

Після виконання тестів результати можна переглянути у звіті:

`build/reports/tests/test/index.html`
